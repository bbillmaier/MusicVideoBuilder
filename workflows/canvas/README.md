# Martini Shot canvas inspection workflows

These are canvas-readable diagrams of the API templates one directory above. They show the same nodes, settings, and connections, but are deliberately **not runnable**: Martini Shot normally fills project objects and `{{placeholders}}` immediately before it submits an API graph.

Open them from ComfyUI's workflow menu under `Martini Shot Inspect`. Change the API templates, then run `node tools/export-canvas-workflows.mjs` to regenerate the companions.
